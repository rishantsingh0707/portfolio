# Rishant Portfolio (Vite + React + Three.js)

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in /dist
```

- Edit your content in `src/data.js` (email, projects, skills, education).
- Add `public/resume.pdf` and `public/photo.jpg` for the download button and your photo.
- Interactive background lives in `src/Background.jsx`.
- Deploy `dist/` to Vercel, Netlify or GitHub Pages.
